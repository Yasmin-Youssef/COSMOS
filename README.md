# 🌌 COSMOS — Space Dashboard

Explore the universe through an interactive space dashboard! COSMOS brings together information about planets, astronomy pictures, and upcoming space launches in one place.

## ✨ Features

* 🪐 **Planets Explorer:** Discover information about planets in our solar system.
* 🌠 **Astronomy Picture of the Day:** Explore space images and astronomy content powered by NASA.
* 🚀 **Upcoming Space Launches:** View information about upcoming space missions and launches.
* 🎨 **Interactive User Interface:** Navigate between different sections of the dashboard.
* 🌌 **Real-Time API Data:** Fetch and display space-related data from external APIs.

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API & Async/Await
* NASA APOD API
* Solar System API
* SpaceDevs Launch Library API

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Run `index.html` using Live Server.
